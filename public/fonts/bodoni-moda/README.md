# Bodoni Moda

Self-hosted display fonts for the Musta Rähni Päevad campaign, using the CSS
family alias `Bodoni Campaign`.

- Semibold: weight 600, optical size 96.
- Italic: weight 500, optical size 96.
- Source: https://github.com/google/fonts/tree/main/ofl/bodonimoda
- License: SIL Open Font License 1.1, included in `OFL.txt`.
